# Reusable Travel + Taxi Website Template

## Stack
Plain HTML + CSS + JavaScript. No framework, no paid dependency.

## Customize a new client
Open `config.js`. Change:
- brandName
- tagline
- logoText / logoImage
- phone
- whatsapp
- email
- location
- instagram
- colors
- hero content/image
- stats
- services
- gallery
- testimonials
- FAQs

## Run locally
Open `index.html` in a browser.

## Free deployment
1. Create a GitHub repository.
2. Upload all files in this folder.
3. In Cloudflare Pages, create a project from the GitHub repository.
4. Framework preset: None.
5. Build command: leave empty.
6. Output directory: `/`
7. Deploy.

Each client can have their own GitHub repo + Cloudflare Pages project, or you can duplicate this template and edit `config.js`.

## Important
Replace demo images and placeholder business information before a client launch.
